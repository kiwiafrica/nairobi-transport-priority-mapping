# Publication checklist

This repository is prepared as a **portfolio preview**, not a completed reproducible research package.

## Review before making it public

- [ ] Confirm you want the research and the extracted thesis figures publicly visible.
- [ ] Confirm that the original thesis, coauthors/supervisors (if any), institutional logos, map layers, and embedded third-party material may be displayed on GitHub.
- [ ] Choose a project license. None has been assigned automatically; do not assume a thesis's pre-existing license applies to all code or third-party data.
- [ ] Confirm the priority-zone results and image labels match the final thesis version.
- [ ] Remove sensitive/private data, credentials, service account files, API keys, or internal project information.
- [ ] Check external geospatial data licensing and required attribution, especially for basemaps, OpenStreetMap and Google imagery/datasets.
- [ ] Add the **original** GEE JavaScript/Python scripts if available (avoid representing newly drafted examples as original research code).
- [ ] Add the QGIS project and only permitted lightweight source data or a data download guide, if available.
- [ ] Provide exact version information, extraction date, parameter settings, environment requirements and instructions needed for reproducibility.
- [ ] Decide whether to link to a publicly hosted thesis or keep it separate from the repository.
