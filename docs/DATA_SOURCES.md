# Data sources and provenance

Sources and time references below were taken from the supplied master's thesis. Source downloads and executable extraction code are **not** included.

| Source | Study input | Relevant caveat |
|---|---|---|
| Dynamic World V1 (Google Earth Engine) | 2016 and 2023 built-up probability composites | Results depend on selected probability threshold and temporal compositing |
| ESA WorldCover 2021 | Reference for built-up threshold comparison | Reference year differs from both target years |
| Google Open Buildings | Building counts and building-volume proxy | Confidence filter and footprint/height uncertainty |
| Kenya National Bureau of Statistics (KNBS), 2019 | Zone-level population proxy | Disaggregated from available population geography using areal assumptions |
| OpenStreetMap POIs | Commercial, education/health, and industrial indicators | Coverage and mapping completeness vary spatially |
| Digital Matatus, 2019 | Matatu stop counts and stop density | Stop density is not equal to service frequency or passenger capacity |
| JICA NIUPLAN, 2013 | Comparison zone framework and plans | Digitized study boundaries are not official source GIS polygons |

**Do not upload third-party datasets directly unless their specific redistribution conditions permit it.** Link to authoritative source pages and document exact versions/queries when you add the original scripts.
